# 6轴机械臂主控系统

基于 STM32F407 的 6 轴机械臂控制器，通过 CAN 总线与 SMD 智能电机驱动器通信，支持 PC 端 ASCII 协议实时控制。

## 硬件平台

| 组件 | 型号/参数 |
|------|----------|
| 主控 | STM32F407VET6 (168MHz Cortex-M4) |
| 电机驱动 | SMD 系列智能闭环步进驱动器 (1-6轴) |
| 通信 | CAN2 500kbps 扩展帧, I2C, UART |
| 显示 | SSD1306 128×64 OLED (I2C1, 地址 0x78) |
| 上位机 | UART1 115200bps DMA (PA9/PA10) |

## 通信协议

### 上位机 → 控制器 (UART1)

| 命令 | 格式 | 说明 |
|------|------|------|
| 角度控制 | `A<p1>,<p2>,<p3>,<p4>,<p5>,<p6>B` | 6轴增量脉冲（相对于零点偏置），帧头A帧尾B |
| 心跳 | `OK` | 刷新看门狗，>2s 无心跳自动急停 |
| 急停 | `CD` | 立即停止所有电机并回复 `OK\r\n` |
| 移动 | `EF` | 机械臂各轴移动到当前实际位置（同时刷新看门狗） |

### 控制器 → SMD 电机 (CAN2)

```
 0      1       2       3  ...  N-2        N-1
+------+------+------+-----+-----+------+------+
| 0xC5 | addr | func |  payload  | chk  | 0x5C |
+------+------+------+-----+-----+------+------+
  HEAD                              checksum  TAIL
```

- CAN ID: `0x1000` (扩展帧)
- 波特率: 500kbps (CAN2, PB12/PB13)
- 校验: 累加和取低8位（从帧头到校验位前一个字节之和）
- 多字节参数均采用大端序 (MSB first)
- 支持 60+ 功能码: 位置/速度/力矩模式、PID 配置、原点回归、堵转保护等

### 控制器 → 上位机 (UART1)

| 响应 | 格式 | 说明 |
|------|------|------|
| 确认回显 | `A<p1>,...,<p6>B\r\n` | 返回当前6轴相对位置（绝对脉冲 − 零点偏置） |
| 急停确认 | `OK\r\n` | 急停完成 |
| DMA 错误 | `DMA_ERR\r\n` | UART DMA 重启失败 |

## 核心功能

### 运动控制
- **增量位置模式**: PC 下发增量脉冲 → 加上电零点偏置 → 换算为绝对脉冲值下发 SMD 电机
- **CoG 重心感知排序**: 通过电机2(肩)+电机3(肘)的绝对位置之和估算重心，重心外扩时外关节先回缩、底座最后动，降低倾覆力矩
- **命令去重**: 同一目标脉冲+方向不重复下发，减少 CAN 总线负载
- **重试机制**: 每个关节最多重试 3 次（100ms 超时），任一成功即通过

### 智能夹爪（电机7，力矩模式）
- 非阻塞状态机，TIM1 每 1ms 推进一个状态
- S1: 小力矩逼近 → S2: 轮询相电流，检测接触 → S3: 力矩递增至最大值 → MONITOR: 检测电流稳定性 → HOLD: 降至保持力矩
- 电机全程不离开力矩模式，夹持力由实时电流环维持
- 收到角度命令后自动延时 6 秒执行，给机械臂主体运动留出时间

### 安全机制
- **通信看门狗**: 超过 2 秒未收到任何命令（心跳/角度/移动），自动急停
- **上电零点标定**: 上电时读取全部电机当前位置作为软件零点，验证 ±500 脉冲容差，超限最多重试 3 次
- **紧急停止**: `CD` 命令按 CoG 顺序立即停止所有电机（每轴最多重试 3 次）
- **CAN 事务锁**: 临界区保护的收发锁，防止多任务并发访问 CAN 总线

### OLED 显示
- 实时显示 6 轴目标角度
- 字体: ASCII 8×16（94字符）、数字 8×16（0-9）
- 支持十六进制/八进制数值和数组的调试显示
- 双缓冲: 128×64 帧缓冲 → 整帧刷新到 SSD1306

## 中断优先级

| 中断 | 优先级 | 用途 |
|------|--------|------|
| SysTick | 0 | 1ms 全局时基 |
| CAN2 RX0 | 0 | SMD 帧接收与组装 |
| USART1 | 0 | 上位机协议解析 |
| TIM1 | 1 | 1kHz 位置轮询 + 夹爪状态机 |

## 时钟树

```
HSI (16MHz)
  └─ PLLM÷8 → 2MHz
       └─ PLLN×168 → 336MHz
            ├─ PLLP÷2 → 168MHz SYSCLK
            └─ PLLQ÷4 → 84MHz (USB/SAI)
```

## 开发环境

- **IDE**: Keil MDK-ARM
- **HAL**: STM32F4xx HAL Driver
